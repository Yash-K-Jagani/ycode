# Shortcuts

| Key | Action |
|---|---|
| `Ctrl+C` | Stop generation (discards partial output) / quit if idle |
| `Ctrl+D` | Exit |
| `Ctrl+L` | (reserved) |
| `Ctrl+N` | New session |
| `Ctrl+B` | Toggle right sidebar (folder, model, tokens, spend, tasks) |
| `Ctrl+O` | Cycle installed Ollama models |
| `Ctrl+P` | (palette = `/` commands) |
| `Ctrl+R` | (sessions via `/sessions`) |
| `Ctrl+U` | Clear input (textarea) |
| `Tab` / `Shift+Tab` | Cycle mode Plan → Build → Chat → Thinking |
| `Esc` | Stop generation / close dialogs |
| `↑` / `↓` | Input history |
| `Enter` | Send |
